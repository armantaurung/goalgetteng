# GoalForge - Web Application Pelacak Goal & Habit Harian 🎯

Aplikasi web modern, indah, dan interaktif untuk melacak **Goal Utama**, **Sub-Goal (Milestone Kecil)**, dan **Habit Harian** yang dilengkapi dengan **Visualisasi Pohon Jeruk Orange (Orange Citrus Tree)**, **Kalender Rutinitas Real-time 365 Hari**, **Integrasi Google Calendar**, serta **Reset Harian Otomatis**.

---

## 🌟 Fitur Utama

- 🎯 **Manajemen Goal & Sub-Goal**: Tetapkan tujuan utama dan pecah menjadi langkah-langkah konkret.
- 🍊 **Visualisasi Pohon Jeruk Orange**: Pohon jeruk visual yang tumbuh dari tunas, berbunga, dan berbuah lebat (100% Panen) seiring peningkatan konsistensi habit Anda.
- ⚡ **Matriks Kelompok Habit**: Pengelompokan habit berdasarkan kategori (Spiritual, Physical/Health, Career, Finance, Personal, Custom) dengan label vertikal yang elegan.
- 📅 **Kalender Rutinitas Real-Time Penuh**: Tampilan grid kalender bulanan 365 hari untuk melihat hari mana yang terisi penuh (🍊 100%) dan mana yang kosong.
- 📈 **Progres Ringkas Habit**: Pemantauan akumulasi total hari, total jam latihan, dan mini tree per-habit.
- 📅 **Integrasi Google Calendar**: Ekspor berkas `.ics` atau tambah pengingat acara harian berulang ke Google Calendar secara langsung.
- 🌅 **Fresh Daily Rollover**: Checklist fokus hari ini otomatis menyajikan bilah bersih setiap hari tanpa menghilangkan riwayat pencapaian hari-hari lalu.
- 💾 **Penyimpanan Lokal (localStorage) & Backup JSON**: Seluruh data tersimpan aman di browser Anda dan bisa diekspor/diimpor kapan saja.

---

## 🚀 Cara Menjalankan Secara Lokal

Cukup buka berkas `index.html` di browser web modern pilihan Anda (Google Chrome, Firefox, Microsoft Edge, Safari). Tidak memerlukan dependensi Node.js atau server khusus!
